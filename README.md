# WORKBASE · 企业 Harness 办公台原型

企业定制 Harness 低代码办公台的高保真交互原型，附八题完整设计答卷。

- **在线原型（公开免登录）**：https://julian-harness-workbase.j-w2007.chatgpt.site/
- **完整设计答卷**：https://julian-harness-workbase.j-w2007.chatgpt.site/assessment.html
- **文字版答卷**：[assessment.md](assessment.md)

## 核心设计

对话用于处理新任务、生成工具；反复执行的任务固化为确定性应用。生成与日常运行分开，已发布页面打开时不依赖 Harness。

## 原型可操作内容

1. **我的办公台**：通过预置对话生成报销核对台草稿。
2. **构建与发布**：查看页面 DSL、权限范围和版本；普通员工发布被阻断，业务发布人审核后生效。
3. **应用运行**：搜索、筛选、整数分合计、提交复核、导出 CSV；没有模型网络调用。
4. **模型路由**：演示固定程序优先、机密任务仅内网候选、复杂任务升级等规则。
5. **安全与审计**：记录本机演示事件；版本回滚保留已发生的业务状态。

## 本地运行

无需安装依赖或配置 API Key。直接用桌面浏览器打开 `index.html`，也可以在仓库目录运行：

```sh
python3 -m http.server 8000
```

然后打开 `http://localhost:8000`。完整答卷为 `assessment.html`。

## 推荐演示顺序

1. 办公台点击“报销核对与复核队列”，点击“生成草稿”。
2. 到“构建与发布”，以普通员工尝试发布，观察阻断。
3. 右上角切换“业务发布人”，审核并发布 v2。
4. 打开“应用运行”，观察新增部门筛选。运营部合计 ¥4,048.00，全部记录合计 ¥4,908.00。
5. 选择 BX-1028，提交复核并确认；该行变为已提交状态且不能再次选择。
6. 回滚 v1，确认部门筛选消失，但业务状态保留。
7. 在模型路由选择机密数据或固定规则任务，查看路由理由。
8. 到安全与审计查看记录；左下角可重置本机演示。

## 技术与范围

当前实现为自包含 HTML、CSS 与原生 JavaScript，使用合成样例和浏览器本地存储，不依赖外部脚本。

答卷中讨论的 React / FastAPI / LangGraph / PostgreSQL 等，是拟议生产架构，不能据此认为本原型已经接入这些服务。

- 未接入真实 LLM、企业 SSO、服务端鉴权、业务连接器或真实付款。
- 生成与路由为预置规则模拟，不是通用 Agent 执行或真实性能评测。
- 角色切换、权限检查和审计均为前端演示，不能作为生产安全保障。
- 本机日志可修改；本机存储可能被浏览器清理，不适合保存真实敏感资料。
- CSV / JSON 导出已实现；本次未将浏览器下载结果回读列为已验收。
- 桌面主线交互、版本生效、合计、重复选择阻断和回滚已在预览环境验证。未完成真实手机或 200% 缩放设备验收。
